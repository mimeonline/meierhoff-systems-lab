# Meierhoff Systems Lab

Meierhoff Systems Lab is a public repository for workshops, live coding sessions, talks, experiments, demos, tools, and shared reference assets related to AI systems, software architecture, and system thinking.

## What This Repository Contains

This repository collects practical learning material, small technical artifacts, and reusable supporting resources. It is intended to stay readable, easy to navigate, and suitable for public sharing.

## Structure

- `workshops/`: self-contained workshop material and supporting files
- `live-coding/`: session-ready coding examples and walkthroughs
- `talks/`: talk material, speaker notes, and presentation assets
- `experiments/`: small explorations, prototypes, and technical investigations
- `demos/`: focused demonstrations of ideas, patterns, or tools
- `tools/`: lightweight utilities that support the repository content
- `shared/`: reusable assets, diagrams, and templates used across multiple areas

## Principles

- Practical
- Minimal
- Reusable
- Public-ready
