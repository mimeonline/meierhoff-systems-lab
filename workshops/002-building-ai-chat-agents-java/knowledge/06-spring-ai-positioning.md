# Where Spring AI Fits

Spring AI is useful when a team already works inside a Spring application and wants AI capabilities to align with the rest of the stack.

This workshop deliberately does not use Spring AI because the teaching goal is different.

The workshop wants participants to see:

- how little code is needed for a plain Java baseline
- where the architectural seams really are
- what LangChain4j itself contributes

A helpful rule of thumb:

- choose plain Java for teaching and architecture visibility
- choose Spring AI when Spring integration, dependency injection, configuration binding, and operational conventions are the bigger concern

Spring AI is not the same thing as LangChain4j. They can solve adjacent problems, and sometimes teams compare them too directly.
