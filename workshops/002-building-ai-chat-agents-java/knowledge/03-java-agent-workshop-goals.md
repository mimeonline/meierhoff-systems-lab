# Goals of the Java Agent Workshop

The workshop has five primary goals:

1. show how a plain Java application can talk to an LLM
2. make memory visible as an architectural decision
3. demonstrate that tools add deterministic capability
4. explain MCP as a standard bridge to tools outside the application
5. show why RAG helps when answers depend on local workshop knowledge

The project is intentionally not a production framework template.

It should help participants answer questions like:

- What part is the actual learning code?
- What part is just glue code?
- When should I use direct tools?
- When does retrieval beat prompt-only chatting?

The desired outcome is not "build the most advanced agent." The desired outcome is "understand what each capability changes."
