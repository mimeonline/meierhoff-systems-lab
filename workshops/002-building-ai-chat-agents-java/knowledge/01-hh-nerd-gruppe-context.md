# HH Nerd Gruppe and Workshop Context

The HH Nerd Gruppe is a community-oriented Hamburg tech meetup setting where practical learning matters more than polished product demos.

For this workshop, the intended context is:

- a friendly, technical audience
- hands-on explanations instead of marketing language
- short feedback loops
- architecture decisions that can be discussed live

The workshop is meant to feel like a coding lab. Participants should be able to inspect the running system, ask a question, and immediately see which internal mechanism changed the answer.

One workshop-specific detail is important: the Java session is positioned as the follow-up for developers who liked the earlier Python-based agent workshop but wanted a version that fits better into a typical JVM stack.
