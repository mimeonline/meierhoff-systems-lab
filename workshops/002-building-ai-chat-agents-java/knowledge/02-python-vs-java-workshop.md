# Python Workshop vs Java Workshop

The earlier Python workshop was optimized for speed of experimentation. It used lightweight scripting, faster iteration, and lower ceremony.

This Java workshop has a different goal:

- show architecture in a language many enterprise teams already use
- make explicit boundaries between learning code and infrastructure code
- avoid framework magic
- keep the project locally runnable with plain Java and Maven

Key contrast:

- Python workshop: fastest path to "something agent-like"
- Java workshop: clearest path to "something architecturally understandable"

This distinction matters for RAG. A generic model might talk about Python and Java in broad terms, but it does not know this workshop-specific positioning unless the information is retrieved from local notes.
