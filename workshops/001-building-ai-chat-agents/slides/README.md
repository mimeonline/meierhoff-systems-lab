# Slides

These slides are built with Slidev and are part of the public workshop material for `001-building-ai-chat-agents`.

## Install Dependencies

From the `slides/` directory:

```bash
npm install
```

## Start The Dev Server

```bash
npm run dev
```

Slidev will start a local development server and watch the deck for changes.

## Build The Slides

```bash
npm run build
```

This creates a production build in `dist/`.

## Export The Slides

```bash
npm run export
```

This exports the deck to PDF when the local environment supports Slidev export dependencies.

## Note

The deck is intentionally compact. It supports the phase-based code walkthrough rather than replacing it.
