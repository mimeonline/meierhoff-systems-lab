# Workshops

This folder contains workshop material intended for guided, self-contained learning sessions.

## What Belongs Here

- Workshop-specific instructions and agenda material
- Examples, exercises, and supporting files used during a workshop
- Assets that are only relevant to a single workshop

## What Does Not Belong Here

- Shared assets that are used across multiple folders
- General-purpose tools that are not workshop-specific
- Unstructured notes without enough context to reuse

## Naming

Use lowercase kebab-case for workshop folders. Numeric prefixes are allowed when ordering matters, for example `001-building-ai-chat-agents`.

## Typical Entry

A workshop folder should usually contain:

- a local `README.md`
- any required examples or exercise material
- only the assets needed for that workshop
