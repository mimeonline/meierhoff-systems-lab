# Live Coding

This folder contains material for live coding sessions and walkthroughs that are meant to be followed in real time.

## What Belongs Here

- Session-specific code examples
- Notes or prompts that guide the live session
- Small supporting assets used directly during the session

## What Does Not Belong Here

- Full workshop packages
- Long-term shared utilities better placed in `tools/`
- Reusable assets that should live in `shared/`

## Naming

Use lowercase kebab-case for session folders. Keep names short and descriptive, for example `event-driven-agent-loop`.

## Typical Entry

A session folder should usually contain:

- a local `README.md`
- the minimal code or files needed for the walkthrough
- brief setup and follow-along instructions
