# Tools

This folder contains lightweight utilities that support the repository and its learning material.

## What Belongs Here

- Small helper scripts or utilities
- Reusable tooling that supports workshops, demos, or experiments
- Documentation for how and when a tool should be used

## What Does Not Belong Here

- Large applications or frameworks
- One-off code that only serves a single artifact
- Shared non-code assets that belong in `shared/`

## Naming

Use lowercase kebab-case for tool folders. Keep names short and descriptive, for example `diagram-exporter`.

## Typical Entry

A tool folder should usually contain:

- a local `README.md`
- the minimal source files needed for the utility
- short usage notes and any required prerequisites
