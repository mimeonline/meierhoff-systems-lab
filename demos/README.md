# Demos

This folder contains concise demonstrations of concepts, workflows, patterns, or system behavior.

## What Belongs Here

- Small demo artifacts prepared for teaching or showing a concept
- Focused examples with a clear outcome
- Supporting files needed to run or review the demo

## What Does Not Belong Here

- Broad exploratory work better suited for `experiments/`
- Long workshop material
- General repository tooling

## Naming

Use lowercase kebab-case for demo folders. Keep names short and specific, for example `multi-agent-review-flow`.

## Typical Entry

A demo folder should usually contain:

- a local `README.md`
- the minimal code or assets needed for the demo
- short instructions for how to run, present, or inspect it
