# Talks

This folder contains material for talks, presentations, and technical speaking sessions.

## What Belongs Here

- Slide source files or exported presentation assets
- Speaker notes and supporting references
- Talk-specific diagrams or examples

## What Does Not Belong Here

- Workshop exercises
- General experiments without a talk context
- Shared templates that should live in `shared/`

## Naming

Use lowercase kebab-case for talk folders. Keep names concise and aligned with the talk topic, for example `system-thinking-for-ai-teams`.

## Typical Entry

A talk folder should usually contain:

- a local `README.md`
- slide material or links to presentation sources
- notes, references, and talk-specific assets
