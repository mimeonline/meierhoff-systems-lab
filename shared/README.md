# Shared

This folder contains reusable assets and reference material shared across multiple parts of the repository.

## What Belongs Here

- Common assets used in more than one artifact
- Reusable diagrams and templates
- Reference materials that support multiple workshops, demos, or talks

## What Does Not Belong Here

- Files that only belong to a single workshop, talk, or demo
- Project-specific code examples
- Private drafts or temporary working files

## Naming

Use lowercase kebab-case for subfolders and files. Keep names short and descriptive, for example `architecture-review-template`.

## Typical Entry

A shared resource area should usually contain:

- a local `README.md` when the content becomes substantial
- clearly named reusable files or folders
- material with a defined purpose across multiple artifacts
